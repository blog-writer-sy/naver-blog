# 네이버 블로그 원고 관리

- `공통규칙.md`: 모든 업종에 쓰는 원고 형식과 작성 규칙
- `맛집/`, `건강기능식품/`: 업종 지침(`CLAUDE.md`), 예시·자료(`자료/`), 완성 원고(`원고/`)
- `교육/`: 교육 공통 지침(`CLAUDE.md`)과 세부 분야 5개
  - `게임학원/`, `요리학원/`, `자격증교재/`, `공무원/`, `민간자격증/` (분야마다 `CLAUDE.md`, `자료/`, `원고/`)
- `붙여넣기용/`: claude.ai 프로젝트 지침에 그대로 붙여 넣는 통합본(업종·분야별 1개씩)

사용법: Claude Code 클라우드 세션을 이 저장소로 열고
"[분야][후기성 또는 정보성] 메인 키워드 / 실제 경험"을 알려 주면 원고를 써서 해당 `원고/`에 저장한다.
예시 원고는 해당 분야 `자료/`에 `예시_` 로 시작하는 이름으로 올린다.
사진은 용량 때문에 저장소에 넣지 않는다.
