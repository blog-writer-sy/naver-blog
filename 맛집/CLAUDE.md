## 4. 업종 규칙
- 네이버 플레이스와 정보가 일치해야 한다. 주소, 영업시간, 가격은 받은 정보 그대로 쓰고, 없으면 [확인 필요]로 표시한다.
- 가격은 "○년 ○월 방문 기준"을 함께 쓴다.
- 맛 표현은 "맛있다"로 끝내지 말고 식감, 온도, 간, 양, 곁들임처럼 구체적으로 쓴다.
- 먹지 않은 메뉴를 먹은 것처럼 쓰지 않는다.
- 아쉬운 점은 받은 정보에 있을 때만 꿀팁 형태로 가볍게 넣는다. 예) "웨이팅이 길 수 있으니 다른 지점을 확인해 두는 것도 꿀팁!"
- 원산지, 위생 관련 내용은 매장이 공개한 정보일 때만 쓴다.

## 5. 글 구조 (기준 원고: `자료/예시_오이도 조개구이…txt`)
소제목은 `(★프레임인용구)`를 쓴다. 기본 5개.

0. 도입: (★공정위 문구 스티커) → (대표이미지-1) → "{메인 키워드} ~ 추천할게요..!" → 방문 계기(재방문, 친구 소개 등) → "저장해두고 읽어보세요~~" 식 예고
1. 위치와 주차: 위치 설명(랜드마크에서 도보 몇 분) → `<매장명 정보>` 블록(👉 주소, 전화, 주차, 예약) → 도착 풍경 → 외관 → 웨이팅 꿀팁
2. 매장 분위기와 메뉴 구성: 입구·수조·위생 → 실내 좌석, 단체 가능 여부 → `<대표 메뉴와 가격 구성>` 블록(📌, 주요 메뉴 배경색) → 가격 평가
3. 주문 메뉴 후기 1: 기본 반찬 → 메인 메뉴 등장 → 먹는 장면을 단계별로
4. 주문 메뉴 후기 2: 두 번째 메뉴, 리필·시즌 메뉴
5. {메인 키워드} 후기: 총평 → 동행인 반응 → 강력 추천 → 다음 방문 계획
마지막: `(★지도 삽입:) 매장명` → 해시태그 6~8개(메인 키워드, 메인 키워드+추천, 매장명, 지역+맛집, 키워드 챌린지)

## 6. 맛집 원고 수치 기준
- 메인 키워드: 본문 10~13회 (예시 12회). 소제목 앞 문장마다 "{메인 키워드} 위치는~", "{메인 키워드} 실내는~"처럼 주어로 넣는다.
- 매장명: 5~8회
- 이미지: 18~22장. 사진 1장마다 설명 2~4줄.
- 장면 묘사: 먹는 순서대로 식감, 온도, 소리("자글자글", "쭈우욱~")를 쓴다.

## 7. 글 유형별 적용
- **후기성**: 위 5번 구조 그대로(기준 원고 = 오이도 조개구이 예시). 메인 키워드 10~13회, 이미지 18~22장.
- **정보성**: 특정 매장 홍보 없이 지역·메뉴 정보를 정리한다.
  - 글감: "OO역 회식 장소 고르는 법", "OO 제철 해산물 시기", "OO 해수욕장 가는 법과 주차 정보", "조개구이 맛있게 굽는 순서"
  - 구조: 도입(왜 찾게 됐는지) → 소제목 4~5개(기본 정보, 고르는 기준, 시기·가격대, 꿀팁) → Q&A → 체크리스트
  - 메인 키워드 6~8회. 매장명은 넣지 않는다(꼭 넣으면 마지막에 1회).
  - 여러 매장을 소개하는 "리스트형"은 매장마다 받은 정보만 쓰고, 순위를 매기지 않는다.
