## 3. 분야 규칙 (자격기본법 기준, 가장 중요)
- 자격 과정을 홍보하는 글이면 **자격 종류(등록/공인), 등록번호, 자격 발급기관, 총비용(수강료·응시료·발급비), 환불 규정**을 본문 정보 블록에 넣는다. 받은 정보에 없으면 [확인 필요].
- **국가자격이나 공인자격으로 오인하게 쓰지 않는다.** "국가공인"은 공인민간자격으로 확인된 경우에만 쓰고, 등록민간자격에는 "국가 인증", "정부 인정" 같은 표현을 쓰지 않는다.
- "취업 보장", "고수익 보장", "누구나 바로 창업", "100% 합격" 같은 결과 보장 표현은 쓰지 않는다.
- "평생 무료", "수강료 0원"은 응시료·발급비까지 모두 무료인 경우에만 쓴다. 추가 비용이 있으면 함께 적는다.
- 활용처(취업처, 우대 기관)는 실제로 확인된 것만 쓰고, 기관명을 넣을 때는 근거를 받는다.
- 자격 정보 확인처로 "민간자격정보서비스"를 안내할 수 있다.

## 4. 글 유형별 적용
- **정보성은 A 경험형 / B 가이드형 두 가지다.** 요청에 `[정보성A]`, `[정보성B]`가 없으면 먼저 묻는다. 같은 블로그에서 번갈아 쓰면 글 패턴이 겹치지 않아 좋다.

- **정보성 A 경험형** (기준 원고: `자료/예시_정보A_바리스타 자격증…txt`)
  - 성격: 정보 중심 글에 **1인칭 준비 경험**을 섞고, 교육기관은 **이름 대신 특징으로** 소개한 뒤 마지막에 링크 1개로 연결한다. (공통 규칙 정보성 표보다 이 기준을 우선한다)
  - 제목: `{메인 키워드} + 비교/난이도/준비 과정/취득 방법` 예) "○○ 자격증 취득 난이도 비교와 필기 준비 과정"
  - 구조:
    0. (대표이미지-1) → 제목을 한 번 더 `(★기본인용구 + 굵기)`로 → 도입: 자격증 한 줄 설명 → 내가 알아본 계기(취업·취미) → 헷갈렸던 점 → "지금부터 공유해 볼게요 :)"
    1. {메인 키워드} 종류·난이도 비교: 비교 표 1개(구분/평가방식/난이도) → ①② 유형 정리 → 내가 고른 방향
    2. {메인 키워드} 시험에서 어려웠던 부분: "항목 : 설명" 굵기 목록 4개 → 가장 어려웠던 것 → 이해한 방법(A → B → C 흐름)
    3. {메인 키워드} 준비 과정: 단계 표 1개(단계/학습 내용/확인할 사항) → 스스로 던진 질문 ①②③
    4. {메인 키워드} 교육기관 선택 기준: 기준 1)~4) 요약 → ①~④ "기준 : 설명" 굵기 → 만족한 점 → (★스티커첨부)
    5. {메인 키워드} 취득 후 느낀 점: 달라진 점 → 목적별 ✔ 기준 3개 → 기관 홈페이지 안내 → (★링크 삽입: 교육기관 홈페이지) → (★구분선)
  - 소제목은 `(★말풍선인용구)`. 소제목 바로 앞에 이미지를 둔다.
  - 소제목 다음 첫 문장은 메인 키워드로 시작하고 `(★문장전체 - 굵기 + 배경색 + 글씨색)`.
  - 줄 길이는 25~45자로 후기성보다 길게 쓴다. 감정 표현(ㅎㅎ, ㅋㅋ)은 쓰지 않고 `:)`만 도입·마무리에 1번씩.
  - 메인 키워드 10~13회(예시 13회), 이미지 6~8장, 표 2개, 본문 공백 제외 1,800~2,200자.
  - 다른 글감: "민간자격증 등록·공인 차이", "민간자격증 고를 때 확인할 것(등록번호 조회, 총비용, 환불)", "○○ 자격증 취득 방법과 준비 기간"

- **정보성 B 가이드형** (기준 원고: `자료/예시_정보B_병원코디네이터 자격증 독학…txt`)
  - 성격: **1인칭 경험 없이** 독자에게 안내하는 말투. 과정 페이지에 나온 사실(강의 수, 수강기간, 응시 조건, 합격 기준, 발급 절차)을 순서대로 정리한다. 교육기관 이름과 등록 정보를 본문에 사실대로 쓴다.
  - 제목: `{메인 키워드} {방식} (구체 숫자 + 순서/방식)` 예) "○○ 자격증 독학 (온라인 25강 공부 순서와 시험 방식)"
  - 구조:
    0. (★스티커첨부) → 제목 한 줄 반복 → (★구분선) → 도입: "{메인 키워드} {방식}은 ~에서 시작합니다" 결론부터 → 왜 순서가 중요한지 → 이런 분(퇴근 후, 육아 중 등 독자 상황) → "그래서 오늘은 ~까지 차례로 알려드리겠습니다"
    1. 독학으로 딸 수 있을까?: 준비 방식 → **자격명, 등록 기관, 등록번호** 문장 → `<준비 방식>` 블록 → 실천 팁
    2. 응시 조건은?: `<응시 자격 정리>` 블록 → 과정마다 다를 수 있으니 확인하라는 안내
    3. 강의 어떤 순서로 들을까?: 강의 묶음 1)2)3) → `<강의 묶음 순서>` 블록 → 건너뛰면 안 되는 이유 → 기관 과정 페이지·강사 소개 → (★링크 삽입: 기관명)
    4. 하루 몇 강씩 들을까?: 수강기간 계산 → `<진도 예시>` 블록(주차별) → 일정 팁
    5. 시험은 어떻게 볼까?: 시험 방식·합격 기준 → `<합격 기준 체크>` 블록 → 확인되지 않은 정보는 "홈페이지에서 확인" 안내 → 공부 팁(용어 노트 등)
    6. 발급 신청 전 확인할 것: 신청 메뉴, 결제, 발송 일정, 주의점 → `<발급 전 체크>` 블록 → (★구분선)
    7. 마무리 소제목("~을 시작하기 전에"): 핵심 2~3줄 요약 → 과정 페이지 확인 권유로 끝
  - 소제목은 **질문형** + `(★기본인용구)`. 소제목 바로 다음에 이미지를 둔다.
  - 소제목 다음 첫 문장은 메인 키워드로 시작하는 **결론 문장**("○○ 응시 조건은 ~입니다").
  - 정보 블록은 `<블록 제목>` 다음에 `항목: 값` 형식으로 3~4줄. 이모지 없이.
  - 말투: "~습니다", "~하세요", "~이죠", "~인데요"를 섞는다. "저는", "제가"는 쓰지 않는다. 감정 표현과 이모지는 쓰지 않는다.
  - 받은 정보에 없는 항목(문항 수, 시험 시간 등)은 지어내지 않고 "홈페이지 안내에서 확인하세요"로 쓴다. 이 형식에서는 [확인 필요] 대신 이 문장이 원고에 들어간다. 단, 채팅 체크리스트에는 확인 필요 항목으로 따로 알린다.
  - 메인 키워드 8~10회(예시 9회), 이미지 6장, 표 없음, 본문 공백 제외 1,500~1,900자.
  - 필요한 입력: 과정 페이지 정보(강의 수, 커리큘럼, 수강기간, 응시 조건, 시험 방식, 합격 기준, 발급 절차, 비용, 등록번호, 강사). 과정 페이지 URL을 주면 그 내용을 기준으로 쓴다.
  - 예시 B는 자격명·등록기관·등록번호를 본문에 넣은 점이 좋다. 다만 **수강료, 발급비, 환불 규정이 빠져 있으니** 새 원고에서는 6번 `<발급 전 체크>`나 1번 블록에 넣는다.

- **예시 A 원고에서 따라 하지 않는 부분** (3번 분야 규칙 위반 소지)
  - "고유 자격증 번호가 발급되어 **공신력까지 인정**": 등록번호는 등록 사실일 뿐 공인이 아니다. "등록민간자격(등록번호 ○○○)"처럼 사실만 쓴다.
  - "강의와 시험 응시료가 **무료**": 발급비가 따로 있으면 반드시 함께 쓴다. 예) "강의·응시료 무료, 자격증 발급비 ○원"
  - 자격 종류, 등록번호, 발급기관, 환불 규정이 본문에 없다: 4번 소제목이나 마지막 링크 앞에 `<자격 정보>` 블록으로 넣는다.
  - "취업을 위한 자격증": 취업과 직접 연결하지 말고 "카페 취업을 준비하며 기초를 익히려고"처럼 개인 목적으로 쓴다.
- **후기성**: 수강 동기 → 과정 고를 때 확인한 기준(①②③, `▶ 결론:` 줄은 원고마다 넣을지 정함) → 실제 강의·시험 과정 → 자격증 받기까지 든 비용과 기간 → 활용 계획 → 체크리스트
  - 후기에서도 "이 자격증으로 바로 취업했다"처럼 결과를 일반화하지 않는다. 개인 경험으로만 쓴다.
