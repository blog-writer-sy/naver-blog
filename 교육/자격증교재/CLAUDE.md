# 분야: 자격증 공부 교재

학원이 아니라 **상품(교재) 홍보**다. 교육 공통의 "3. 학원 광고일 때 추가 규칙"은 적용하지 않는다.
글 구조는 건강기능식품의 "선택 기준형"과 비슷하게 쓴다: 이 자격증이 왜 필요한가 → 교재 고를 때 확인한 기준 → 실제 공부 방법 → 체크리스트.

## 3. 분야 규칙
- "합격률 ○%", "판매 1위", "베스트셀러"는 근거(조사 기관, 기간, 서점명)가 있을 때만 쓴다.
- "이 책 한 권이면 합격", "독학 2주 합격 보장" 같은 결과 보장 표현은 쓰지 않는다. 공부 기간은 "제 경우 ○주 걸렸어요"처럼 개인 경험으로만 쓴다.
- 시험 일정, 출제 범위, 합격 기준은 받은 자료나 시행 기관 공고 기준으로 쓰고 연도를 붙인다.
- 개정판이면 무엇이 바뀌었는지 받은 정보로 쓴다. 다른 출판사 교재를 깎아내리지 않는다.

## 4. 잘 맞는 글 유형
- 독학 후기형: 공부 계획표, 하루 공부량, 교재를 어떻게 썼는지(사진: 책 펼친 면, 필기, 플래너)
- 교재 고르는 기준형: 최신 출제기준, 기출 수록 범위, 해설 상세도, 인강 제공
- 자격증 정보형: 시험 개요, 응시 자격, 준비 순서(교재는 자연스럽게 소개)
