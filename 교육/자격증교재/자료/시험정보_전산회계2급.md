# 전산회계 2급 공식 시험 정보

출처: 한국세무사회 국가공인자격시험 누리집 (2026-11-11 검색으로 확인)
- 시험 개요: https://license.kacpta.or.kr/web/info/info_outline.aspx
- 전산회계 2급: https://license.kacpta.or.kr/web/info/info_outline2.aspx

| 항목 | 내용 |
|---|---|
| 주관 | 한국세무사회 (국가공인 자격시험) |
| 시험 시간 | 60분 (12:30~13:30), 이론과 실무를 함께 |
| 이론 | 30%, 객관식 4지선다형 |
| 실무 | 70%, 전산세무회계프로그램(KcLep) 이용 |
| 합격 기준 | 100점 만점에 70점 이상 |
| 이론 범위 | 회계원리: 당좌자산, 재고자산, 유형자산, 부채, 자본금, 수익과 비용 |
| 실무 범위 | 기초정보 등록·수정 20%, 거래자료 입력 40%, 입력자료 및 제장부 조회 10% (구분별 ±10% 조정 가능) |
| 기타 | 신분증 없으면 응시 불가. 장애 응시자 20분 연장 |

확인 못 한 것: 2026년 시험 일정·접수 기간, 응시료, 최근 회차 합격률.
누리집은 이 클라우드 환경에서 직접 접속이 끊겨(해외 접속 차단으로 보임) 검색 결과로 확인했다. 발행 전 누리집에서 한 번 더 확인한다.
