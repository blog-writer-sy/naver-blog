## 확인 못 한 것
- 응시자격: Q-Net 상세 페이지에서 직접 확인하지 못함. 상위 글은 "제한 없음"으로 안내. 발행 전 확인
- 필기 면제 기간, CBT 시험일·시험장 선택 방식: Q-Net 안내에서 확인 필요
- 실기 문항 수(상위 글 일부 "18문제 내외, 사례형 추가"): 공식 근거 확인 필요
